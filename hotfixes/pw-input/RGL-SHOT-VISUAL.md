# RGL 仅发射时显示蓄力特效

第四层修订：原脚本将“已选中且装填完毕”同时用于内部充能和蓄力特效。现在保留内部充能、就绪、弹药和目标检查，只将可见特效及配套蓄力声改为实际弹丸发射确认后触发，持续约 1 秒。切换离开 RGL、时钟倒退、飞机离场会清除显示状态；重新选择不会重播。原发射特效和射击声保留。

使用现有 100 ms 更新回调，不新增高频循环。仅保存身份字符串和时间，实际弹丸池首次建立基线不会触发显示。未达到发射条件时按键不会播放；这是实际发射触发，不是单纯按键触发。

适配精确匹配的 PW-MkI 1.2.0 两份脚本，发布工具生成本地补丁，仓库不分发完整 PW 脚本。按 README 和 BLMU-QAAM.md 部署前三层，退出游戏后执行：

```powershell
python tools/deploy_rgl_visual.py apply
python tools/deploy_rgl_visual.py check
```

回退：`python tools/deploy_rgl_visual.py rollback`。先撤销本层，再回退 BLMU 第三层及更早修订，保留备份与部署记录。
